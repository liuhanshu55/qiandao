# 弈剑阁 · 每日签到系统（局域网版）

一个面向武术协会的多人签到系统。管理员的电脑运行服务器，同学们用手机连同一 WiFi 打开网页即可签到，数据实时共享。

## 文件说明

| 文件 | 作用 |
|------|------|
| `server.js` | Node.js 服务器（零依赖，无需安装任何包） |
| `index.html` | 网页前端（签到 / 统计 / 管理） |
| `data.json` | 数据文件（首次运行自动生成，含成员、签到记录、时段、密码） |
| `启动服务器.bat` | 双击一键启动服务器 |
| `签到页面.html` | 旧的单机版（无服务器，仅本机数据），可忽略 |
| `*.jpg` | 社团宣传图（3D 旋转背景） |

## 启动方法

### 方法一：双击启动（推荐）
双击 `启动服务器.bat`，保持黑色窗口不要关闭。

### 方法二：命令行启动
```bash
node server.js
# 端口被占用时换端口：
node server.js 8080
```

启动成功后，窗口会显示类似：

```
本机访问：   http://localhost:3000
局域网访问： http://192.168.1.100:3000
```

## 使用流程

1. **管理员**：在服务器这台电脑上打开「管理」页，登录后把默认成员名单改成真实名单。
2. **分享地址**：把「局域网访问」地址发给同学（管理页里也有地址和二维码）。
3. **同学签到**：手机连同一 WiFi，打开地址 → 选姓名 → 点「签到」→ 弹出「你已签到成功」。
4. **看统计**：「统计」页查看单日缺席名单、本周签到次数、全勤鼓励。

## 功能清单

1. 每日签到（每天自动刷新），点击弹出「你已签到成功」
2. 单日缺席统计（可按日期查询未签到姓名）
3. 当日未签到提醒（附「你当日还未签到哦」，可一键复制发群）
4. 每周大统计（公开所有人本周签到次数）
5. 管理端：调整特殊时段是否需要签到、加入/移除成员、改密码
6. 社团图片 3D 旋转背景
7. 每周全勤自动鼓励（「你很棒！」等）

## 注意事项

- 服务器和同学手机必须连**同一个 WiFi / 局域网**。
- 如果同学手机打不开，通常是 Windows 防火墙拦截，需在防火墙中放行 Node.js 或 3000 端口。
- 数据保存在 `data.json`，请勿随意删除；如需备份直接复制该文件即可。
